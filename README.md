# Sigma 耳机 Bug Tracker · 只读前端 v2

本仓库的前端是飞书多维表格侧边栏插件。v2 只读取当前用户有权访问的表格：显示当前状态存量，并按北京时间、目标状态和来源记录 ID 去重统计每日转入。

> GitHub 提交或本地构建成功不代表飞书原插件已经更新。必须通过该插件的实际发布渠道更新，并从原插件入口验收。不要新建同名插件来替代原插件。

## 功能与边界

- 当前未解决＋重新打开总量，以及独立的待验收总量；待验收不包含持续测试。
- 三类每日转入：未解决、重新打开、待验收。同一记录同日同状态重复日志只计一次，转走后保留当日转入事实。
- 历史存量只读已有历史表，缺失日期留空，不回填或伪造历史。
- 主表和日志表固定绑定，不跟随当前活跃视图；Base 身份不匹配时停止读取。
- 人工刷新、60 秒刷新、记录事件刷新；按读取权限和复制权限限制数据与 CSV 导出。
- 前端不创建、编辑或删除任何表格、字段、记录、自动化或权限；不使用 App Secret，不调用旧版快照、迁移、Webhook 设置功能。

## 本地验证

使用 Node.js 24+：

```powershell
npm ci --ignore-scripts
npm run check
npm run test:browser
```

`check` 包括 41 项单元/集成回归、应用只读静态检查和 Vite 生产构建。浏览器检查使用独立的 Chrome 资料目录和模拟数据，阻止非本地页面请求；只有 Edge 时先设置 `$env:PLAYWRIGHT_CHANNEL='msedge'`。

```powershell
npm run preview
```

在终端给出的地址后加 `?demo=1` 才会显示模拟界面。真实飞书验收不能带 `demo=1`；独立浏览器无法代替飞书宿主身份和权限验证。

## 旧采集与通知任务

`cron` 和 `.github/workflows` 中原有脚本/触发器保留，**不属于只读前端运行路径**；不要运行它们来测试 v2。这些旧任务仍可能写表或发送通知，不能把整个仓库宣称为只读。

- `collect.yml`：定时或手动触发；没有 push 触发器。
- `notify.yml`：`repository_dispatch` 触发；没有 push 触发器。
- `cron/package.json` 显式保留旧任务的 CommonJS 解释方式，防止前端根包的 ES 模块声明改变旧任务环境。

本次前端更新不启停这些任务、不调用旧回填脚本、不修改飞书自动化。旧公开脚本中发现硬编码凭据，应由维护者单独轮换并审查历史暴露；新前端不引用或使用这些凭据。
