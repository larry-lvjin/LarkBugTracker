数据来源与统计说明

全表口径：固定读取 Bug 主表，不跟随当前选择的视图或筛选条件。只读当前用户有权限看到的记录；高级权限可能限制数据范围。

实时：插件可见时每 60 秒刷新，并监听记录变化后防抖刷新。自动化日志可能延迟，插件不会查询或改变自动化状态；页面关闭不影响已经启用的飞书自动化。

新增：按“日期＋目标状态＋来源记录 ID”去重。创建时直接赋初始状态不在这三条更新规则的明确覆盖范围内；不将当前状态、库存差值或旧的“其他到…”列当作转入事件。

覆盖：启用时间依据用户报告。出现日志只能证明有事件被记录，不能证明整个日期完整、规则从未失败。采集前、尚未有首条日志、读取失败的数据不伪装为已验证的 0。

历史库存：只读已有 BugStats_History 的日期、未解决、重新打开、待验收。缺列、缺日期不补零；冲突日期不选取任意一行。只记录三个目标的转入不足以还原全部历史库存。

本轮读取诊断

不需要 App Secret 或 HTTP 接收服务。不创建/修改任何表格、记录、字段或自动化，不保存原始 Bug 数据到浏览器存储。显示偏好仅保存在本机。
